# 進度

工作單位是票（`.scratch/<里程碑>/issues/NN-slug.md`），狀態在票的 `Status:` 行。這裡只記各里程碑的閱讀指引、session 紀錄、偏差與決定。

本檔只留進行中的里程碑。封存由里程碑的驗收票做，同一個 commit：它的 session 紀錄與偏差整段移到 `docs/archive/<里程碑>.md`，逐列比對沒有遺失；里程碑表的備註換成那個檔的連結。封存後再加一列 session 紀錄，票欄標下一個里程碑（例如 `M1 準備`），「下一步」寫它的開工指令，這一列留在本檔。

- 2026-11-10 D 重做：擁有者已定、重做時照舊的產品決定（佇列與播放模式見 brief §6）：
  - 音樂庫的歌單用封面網格；搜尋結果照舊版混排（歌單中與線上結果），加音源篩選。
  - 必須保留：音源與存取等級（VIP、試聽）的標識、桌面的右側詳情面板；帳號與插件管理從設定進入。
  - 播放頁背景跟封面取色；桌面播放頁的「歌詞／佇列」切換放在頂列右側。
  - 佇列：隨機與循環是兩顆帶文字、各自獨立的切換鈕，循環依序是關、列表、單曲；點「佇列」標題捲回正在播放，不另放「正在播放」列或定位鈕。
  - 加入歌單對話框：除了本地歌單，也列出選取曲目所屬音源、自己帳號底下的遠端歌單，各音源預設收起、點開才載入；對話框本身就是建立與加入的確認（brief §7），取消勾選遠端歌單要再確認一次。
  - 設定不提供字體選項。匯入舊版備份時，播放歷史與電台變淡、略過並說明原因（新版之後有了這兩個功能再匯入一次）。
- 2026-11-10 D 重做 B 看稿意見（擁有者；原文與附圖在 `docs/design/feedback/2026-11-10/`）。A 版在 main，可用 `git show main:docs/design/<頁>.html` 取出來看；這次不再需要和 A 隔離：
  1. 不要捲動收合：往下捲時導覽與迷你播放器維持原樣，不縮成一排圓鈕（和先前選外殼 A 時「捲動時不收合」一致）。切換分頁時選取膠囊的滑動與拉長保留（擁有者確認只指捲動收合）。
  2. 進度條改用 A 的樣式：狀態列底下一條細的強調色進度線（A `playlist.html`「刷新中」的 `.rfs`），不要 B 歌單頭部那張「正在刷新…」卡片。
  3. 匯入歌單頭部拿掉「每天自動刷新／正在刷新」與「複製成本地歌單」那張卡片：複製成本地歌單移進右上「⋯」選單；「⋯」左邊的多選鈕也收進「⋯」，頂列只留「⋯」。刷新狀態改成第 2 點的細進度線。
  4. 桌面播放膠囊緊貼左側側欄，要留出間距。迷你播放器（手機與桌面）多做幾版讓擁有者選，其中至少一版參考 A 書脊式迷你播放器「已播放的部分底色不同」的進度表現（A `shell-a.html` 的 `.spine`）。
  5. 預設不用強調色（原 B 案 `data-accent="none"`），設定的「外觀」讓使用者自選強調色。
  6. 確認對話框列出的曲目要有封面（像 A 的遠端移除確認）。
  7. 播放頁手機：預設是封面，向左滑是歌詞、向右滑是佇列，取代底部「封面／歌詞／佇列」分段控制；要有頁面指示（例如三個點）。代價是不能用左右滑封面切歌，稿上要寫明。
  8. 播放頁的音源膠囊（網易雲音樂｜會員｜無損 FLAC）太大，縮小。
  9. 選單與確認的形式（擁有者待確認，以下是建議）：手機上一首歌的「更多」用底部 sheet（A 的形式）；遠端移除這類確認用置中對話框（B 的形式）加封面，和選單的形狀不同，避免連點誤刪。桌面照舊用右鍵選單與置中對話框。
