# FMP 新版路線圖

> 里程碑的順序、狀態、開工前要讀什麼。還沒開工的里程碑在下面各有一小節；開工 session（`/to-tickets docs/roadmap.md 拆 <里程碑> 的票`）把那一節細化成 `.scratch/<里程碑>/spec.md`，這裡縮成一行連到它。插入里程碑用小數（`M1.5`），已有的編號不改。不是里程碑的工作（文件瘦身、審計）也在表裡佔一列，「里程碑」欄以它的目錄名開頭（`gates 閘門補齊` 對 `.scratch/gates/`）；`scripts/check_docs.py` 擋有票卻沒列的目錄。同時有兩批票可以做時，只有一列是「進行中」，另一列的狀態寫明排在誰之後（`未開工，排在 M1 之後`）；要先插做另一批，就把兩列的狀態對調。`python3 scripts/next_step.py` 照這些狀態算出下一步。

## M1.5 YouTube 與網易雲

目標：另外兩個音源都能搜尋、播放，首頁的近期熱門補齊三個音源。

- youtube、netease 插件的搜尋、串流解析與排行榜。youtube 插件的線索：tag `archive/youtubejs-probe-20261106`（把 YouTube.js 打包成插件的實驗，先查證再沿用）。Apple 平台的 YouTube 一律選 m4a/AAC（brief §6）。
- 依音源限流與重試（插件請求經宿主網路層；ARCHITECTURE〈主要依賴〉HTTP 一列寫「還沒做」）：兩個新音源加上 M1 的預載與重解析，請求量變多。一起補 log：宿主網路層的「請求 -> 狀態」是 debug 級，release 版的 HTTP 412 限流與回 200 但內容是風控碼的回應都沒有紀錄（M1 票 15 查到，2026-11-19 協調者記）。

M0 留下的（票 12 歸屬與 2026-11-14 回顧）：

- 串流網址比對 manifest 宣告的媒體網域並限 https：現在 `resolveStream` 回傳的網址只檢查是 http(s) 絕對網址，header 照單全收，原生播放器連線繞過宿主網路的網域白名單（ADR 0038）。三個插件的 CDN 一起定 manifest 的格式。封面圖片的網址也由插件給、不經宿主網路層（ARCHITECTURE〈快取〉），一起處理。
- 網易雲的串流簽名在路徑裡，`redact` 只看 query：由插件宣告網址哪一段要遮（票 06）。YouTube 的簽名參數（`s=`、`key=` 這類名稱）同樣遮不到，一起做。
- CDN 回 `application/octet-stream` 時 Apple 平台能不能播（事實 M5 沒重驗的部分），YouTube 重驗。

驗收：四個平台上，三個音源各搜尋並播放一首；首頁的近期熱門有三個音源的排行榜。

## M2 帳號與存取等級

目標：三個音源都能登入，會員狀態與存取等級正確呈現。

- 三音源的 QR 與 WebView 登入（YouTube 用 WebView 加貼 cookie）、憑證存放、登出。
- 會員狀態、存取等級徽章、音質選擇、試聽處理（brief §5.4）。
- 播放失敗時先降一級音質再跳下一首（brief §6；M1 的失敗處理沒有這一步，2026-11-14 回顧定）。
- B 站登入憑證自動續期：舊版啟動時照 B 站的刷新流程換新 cookie（`lib/services/account/bilibili_account_service.dart`），不續會定期掉登入；做在 bilibili 插件的登入能力，續期失敗時提示重新登入（2026-11-19 文件審查，擁有者同意）。
- 帳號頁的「檢查帳號」按鈕、會員到期前 14 天提醒、啟動時靜默檢查一次（brief §5.4、`docs/design/DESIGN.md` §9）（2026-11-19 文件審查，擁有者同意）。
- 音訊格式與串流類型偏好（舊版的格式優先序，例如 YouTube 偏好 Opus 或 AAC），接在插件列出音質的同一個介面；Apple 平台只能用 AAC（事實 M5），偏好只在 Android 與 Windows 有作用；設定的音質子頁先補稿給擁有者看（2026-11-19 擁有者定）。
- 試聽片段的時長：M1 票 06b 讓畫面只在播放器回報的時長和曲目時長差 3 秒或 1% 內時才採用（擋 Apple 平台串流被截短）；做試聽時串流要標明自己是片段，片段改用播放器的時長（2026-11-18 協調者記）。
- 照設計稿實作：帳號頁（從設定進入）、設定的音質與「播放時使用登入狀態」、播放頁的音源膠囊與試聽、需驗證的流程。

M0 留下的（票 12 歸屬）：

- `flutter_inappwebview` 的平台設定清單（票 04 的 Comments）與 Apple 端退回 CocoaPods（事實 K17）：docs/development.md〈平台〉、§4 的前置條件跟著改。
- 登入憑證的遮蔽：插件宣告額外的敏感名稱交給 `redact`（例如 B 站單獨出現的 `SESSDATA=`，票 06）。
- 宿主擋掉插件給的串流 header 裡的憑證（Cookie、Authorization；事實 F4）。

驗收：四個平台上，三個音源都登入成功；VIP、試聽歌曲的標示與播放行為照 brief §5.4。

## M3 音樂庫與遠端歌單

目標：本地歌單、匯入歌單、遠端寫入都可用，並能搬入舊版資料。

- 本地歌單、匯入歌單與刷新、複製成本地歌單。
- 資料庫檔壞掉時的處理：M1 票 10 的做法是把整個檔改名另存（`fmp.sqlite.unreadable-<時間>`）、開新的空庫並提示；歌單也存進同一個庫之後，要決定使用者怎麼找回或還原那份備份，不能讓歌單看起來「不見」（2026-11-18 協調者記，票 10 的 Heads up）。
- 遠端寫入與寫入前確認。
- 照設計稿實作：音樂庫、歌單詳情、加入歌單對話框、搜尋的「歌單中」、播放頁頂列的加入歌單、首頁的最近更新的匯入歌單；設定的刷新間隔與「資料 → 匯入舊版備份」。
- 匯入舊版 JSON 備份。
- 側欄與細欄的歌單清單、側欄「歌單」旁的 ＋ 就地新建（`shell.html`、`library.html`）；首頁第一次打開時的「匯入歌單」按鈕加回來（M1 票 18 先拿掉）；帳號卡的「歌單」按鈕列出遠端歌單並匯入（`account.html`）（2026-11-19 文件審查，擁有者同意）。
- 舊備份裡的歌詞配對與設定怎麼處理（M3 時還沒有歌詞功能），開工時定（2026-11-19 文件審查，擁有者同意）。
- 曲目的網址與播放數要不要存進資料庫：M1 票 14 只放記憶體，佇列重開後沒有；歌單也存曲目時一起定（2026-11-19 協調者記）。

驗收：用擁有者指定的測試歌單做遠端加入、移除各一次；匯入一份真實的舊版備份，筆數對得上。

## M3.5 下載與音訊快取

目標：曲目能下載離線聽；正在播與下一首自動存到磁碟，重播與切歌不受網路與 CDN 斷線影響（2026-11-19 擁有者同意排進第一版）。

- 先補設計稿（D 設計稿沒有）：下載鈕與進度、已下載頁、設定「儲存空間」的快取上限與清除；先給擁有者看。
- 下載佇列、並行數、暫停續傳、失敗重試；B 站 CDN 中途斷線（事實 F24）要從斷點接著下。
- 磁碟快取：正在播與下一首整首存下、容量上限、最久沒播的先刪；與下載共用檔案位置與曲目對應。
- 下載不給使用者設定，用固定值：同時下載數固定、只存封面不存頭像、預設路徑、不做「同步本機檔案」（舊版有這些設定）（2026-11-19 文件審查，擁有者同意）。
- 各平台檔案位置與權限；和 Apple 平台的 HLS 包裝（ADR 0040）怎麼接；ARCHITECTURE〈快取〉的「音訊：沒有磁碟快取」改寫（草稿先給擁有者）。

驗收：四平台各下載一首、斷網後能播；播過的曲目斷網重播能播完；快取到上限時刪最久沒播的。

## M4 歌詞

目標：播放頁顯示歌詞。

- netease、lrclib 插件的歌詞能力。
- 自動匹配、手動搜尋、偏移調整、翻譯並排。
- 照設計稿實作：播放頁的歌詞畫面、歌詞搜尋、設定的歌詞群組、桌面詳情面板的歌詞分段。
- 設定「儲存空間」的歌詞快取用量與清除（`settings.html`）（2026-11-19 文件審查，擁有者同意）。

驗收：四個平台上，三個音源的曲目都能顯示同步歌詞。

## M5 第一版發佈

目標：發佈 `app-v2.0.0` prerelease，交給擁有者試用。

- 照設計稿實作：插件頁（含插件更新，brief §5.1）、設定頁其餘群組（儲存空間、匯出診斷、關於）；三語補齊。
- 效能量測（brief §15）。
- Windows 單一實例：再開一次 App 時叫回原本的視窗，不開第二個（舊版 `windows/runner/main.cpp`）；兩個實例會同時寫同一個資料庫。macOS 見事實 M7（2026-11-19 文件審查，擁有者同意）。
- `app-release.yml` 與四個平台的安裝檔（brief §16）。
- 重新開啟 `.github/dependabot.yml` 的 GitHub Actions 版本更新（2026-11-06 因舊版凍結而關閉）。

驗收：四個平台的安裝檔都裝得起來並能播放；效能達標；擁有者試用後同意發佈。

## 不排里程碑

驗收與回顧時留下、沒有排進任何里程碑的項目，每條一行、附出處。有 repro 或使用者要求再開票。

- `osascript -e 'quit app "FMP Dev"'` 回 -128，原因沒查（M0 票 12 的觀察）；只影響 macOS 實跑指令的收尾。
- 把 `ADB_MDNS=0` 放進擁有者的登入環境（含 Orca）：擁有者機器的設定，不是 repo 的事（M0 票 02b；docs/development.md〈其他已知怪癖〉）。
- Flutter 從 3.47.5 升到 3.50（2026-11-11 發佈，內建 Material 從這版起 deprecated，事實 T1）：升級前照 ARCHITECTURE〈風險與回寫點〉用 inappwebview 的實驗重建 iOS、macOS，四平台重驗；M1 開工時決定不在設計系統的票裡升（`docs/decisions.md`）。
- M0 各票 code-review 判「影響小」或票 12 判不做的小發現（約 35 項，列在各票的 Comments）：不另開票，之後的票碰到那段程式時順手改（2026-11-14 回顧）。
