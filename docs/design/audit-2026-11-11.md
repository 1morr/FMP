## 2. 佇列

| | 舊版 | 新版（brief §6、progress 2026-11-10、稿） |
| --- | --- | --- |
| 佇列頁顯示 | 永遠是原順序；隨機順序藏在背後（`services/audio/queue_manager.dart:742-757,830-842`） | 永遠是播放順序：開隨機時正在播的移到最上、其餘打亂；關掉恢復原順序 |
| 播過與接下來 | 頂部「正在播放第 N 首」橫幅、跳頂／跳底鈕（`queue_page.dart:225-236,303-336`） | 正在播的下方一條摺線，以上播過（變淡）；點「佇列」標題捲回，不放定位鈕 |
| 隨機＋列表循環 | 下一輪同一個順序（未見重新打亂，不確定） | 每輪重新打亂 |
| 隨機時「下一首播放」 | 新索引隨機插進剩餘順序，不保證下一首（`queue_manager.dart:844-857`） | 一定是下一首 |
| 臨時播放 | 佇列頁看不出來；快照只在記憶體（`audio_provider.dart:609-657,1012-1060`） | 佇列裡插卡片、播放頁頂列寫明；重啟不保留（照舊版） |
| 清空 | 會確認（`queue_page.dart:420-430`） | 會確認，清空後停止播放 |
| 進度保存 | 有「恢復播放進度」設定（`data/models/settings.dart:259-265`） | 一律保存，**設定開關已拿掉**（brief §6） |

2026-11-11 擁有者照建議定案：隨機時拖動或「下一首播放」插入的曲目，關掉隨機後排在正在播放那首的後面；用 × 移除正在播的那首就接著播下一首。
