## Direction contract

THESIS: 一個音樂載體，三個音源的曲目在同一張清單裡；控制像液態玻璃浮在實心內容上，會折射、會變形。拒絕的預設：Material 底部導覽加紫色主題色的舊版，以及把 Apple Music 原樣換皮。

OWN-WORLD: 近黑帶一點紫的底（深）與純白底（淺），內容實心；控制是會折射的玻璃膠囊，邊緣高光、色調隨底下內容翻轉。預設沒有強調色，選取與主要動作用主文字色；使用者可在設定選堇紫、靛藍或青綠。音源標識是三個自繪的彩色小符號，存取等級是金色實心「會員」、金框「付費」、藍色半圓「試聽」三種形狀。封面是唯一的大面積顏色。

STORY: 使用者打開就看到自己的歌單封面牆，點一首歌就播；每一列都能一眼看出音源與能不能完整聽；要寫到音源上的動作都會被清楚確認。

FIRST VIEWPORT: 手機：大標題「音樂庫」與右上玻璃按鈕組，下方兩欄封面網格；底部三層玻璃：迷你播放器膠囊、三項導覽膠囊、右側搜尋圓鈕。捲動時不收合，外殼維持原樣。桌面：左側浮動玻璃側欄（搜尋、音樂庫、佇列、全部歌單、設定），中間內容，右側詳情面板，底部浮動播放膠囊。

FORM: 使用者指定 iOS 26／macOS 26 Liquid Glass 世界，參考 Apple Music 的導覽與迷你播放器。seed: none (pinned)

SIGNATURE: 會折射的玻璃：SVG 位移貼圖做出凸面邊緣的透鏡變形與色散；換分頁時選取膠囊滑動拉長（捲動不觸發任何形變）；玻璃依底下內容自動翻轉明暗。玻璃分三級（折射／標準／最低），對應 Flutter 的 premium／standard／minimal 與 Windows 的上限。
