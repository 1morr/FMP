# 08: 播放模式：隨機與循環

Status: done
Blocked by: 07
讀: brief §6；`docs/design/queue.html`、`docs/design/player.html`；spec〈共同規則〉

## What to build

有兩個獨立的播放模式控制：隨機（開、關，真打亂）與循環（不循環、列表循環、單曲循環），可以同時開，照 brief §6：

- 開隨機時正在播的那首移到最上方，其餘打亂排在後面；佇列頁永遠是播放順序，摺線在正在播的那首下方。
- 關隨機時恢復原順序，從正在播的那首在原順序裡的位置繼續；隨機時拖動過或用「下一首播放」插進來的，關掉後排在正在播的那首後面。
- 隨機加列表循環：播完整串重新打亂再播一輪；只開隨機：播完就停。
- 隨機時「下一首播放」一定是下一首，拖動直接改播放順序。

控制放在迷你播放器以外照稿的位置（佇列頁；播放頁在 16 接上）。
