## What to build

全螢幕播放頁照稿，點迷你播放器、播放膠囊打開：手機是「佇列 ← 封面」兩個畫面左右滑（沒有插件宣告 `lyrics`，歌詞畫面不出現，spec〈共同規則〉），打開在封面，有頁面點點，封面不能滑動切歌；桌面是兩欄，頂列右端切換佇列（歌詞的切換不出現）；頂列中間寫播放來源。背景用封面色（`DESIGN.md` §2.3）。控制：播放與暫停、上一首、下一首、進度拖動（seek）、隨機與循環。⋮ sheet 只列 M1 有的項目。

播放頁音源膠囊（`DESIGN.md` §6.6）照稿，M2 的會員、音質部分不出現。曲目資訊在 17。

## 驗收

- [ ] 播放頁在三種寬度、深淺色的截圖和 `player.html` 對得上（封面、佇列畫面、滑到一半、⋮ sheet、桌面兩欄）。
- [ ] 進度拖動、播放模式、上一首、下一首有 widget 測試。
- [ ] 封面色從封面取得，取不到時照稿的預設；有測試。
- [ ] macOS 桌面播放頁蓋住側欄時，紅綠燈照 `player.html` 留在左上、不壓到播放頁內容：紅綠燈的位置由 `platform/` 的 `TrafficLights` 告訴原生端（票 05d），只在側欄被拆掉或整頁蓋住時才送「沒有燈位」，播放頁疊在原畫面上時要自己送播放頁的燈位；截圖從啟動後不動視窗拍（2026-11-17 協調者加，票 05d 的 Heads up）。
- [ ] 桌面底部播放膠囊可以改進度（`DESIGN.md` §5.1 書脊式：點或拖膠囊空白處、拖折線）；手機迷你播放器照稿只顯示。滑鼠移上去時有提示：游標變成可拖、折線稍微加粗、顯示滑鼠位置對應的時間，提示的樣子先出稿給擁有者看；點與拖有 widget 測試，Windows、macOS 用真滑鼠實跑一次（改到外殼底部，照 development.md 的真滑鼠例外）（2026-11-18 擁有者同意加進這張票，舊版迷你播放器 hover 可改進度）。
- [ ] 四平台實跑：從迷你播放器打開、拖進度、滑到佇列畫面，讀回畫面。
- [ ] 桌面鍵盤（`DESIGN.md` §10）：Space 播放／暫停、←／→ 跳 5 秒、⌘←／⌘→ 上一首／下一首（Windows 用 Ctrl），在 App 任何頁面都有作用、輸入框有焦點時不攔；有 widget 測試（2026-11-19 擁有者同意，文件審查發現）。
- [ ] 無障礙照 `DESIGN.md` §10：這張新增的可聚焦元件有 2px 強調色焦點外框（offset 2）、手機點擊區補到 44（〈稿內不一致與實作注意〉第 2 點）、系統開「減少動態效果」時照 §3.4 改淡入淡出、不彈跳；各一條 widget 測試（2026-11-19 擁有者同意，文件審查發現）。
- [ ] 全部檢查綠燈（`dart run tool/check.dart` 完整版）。
