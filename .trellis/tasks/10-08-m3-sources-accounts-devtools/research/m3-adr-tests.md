方法：測試名稱用 grep 在 `app/test/`、`app/integration_test/`、`app/packages/fmp_lints/test/` 確認存在；
插件端的項目（判定表、錯誤對應、契約 fixture、CI）在 `fmp-plugins` 的 `main`（`6fe837c`）找
`*/test/*.test.js`、`*/checks.json`、`*/fixtures/`、`.github/workflows/ci.yml`。
PR 用 `git log -S"<測試名>"` 找第一個加入該測試的 commit，再找合併它的 merge commit，
並對照 `gh pr view` 的描述。測試檔路徑省略 `app/` 前綴；插件端的檔案前面寫 `fmp-plugins:`。
沒有實際跑 `flutter test` 或 `npm test`。
「PR」欄寫第一個加入該測試的 PR（FMP 端寫 `#`，插件端寫 `p#`）；與表上 PR 編號不同時在備註說明。
「結果」：有＝找到測試或 PR 描述；部分＝只涵蓋子項目的一部分；沒有＝找不到。
