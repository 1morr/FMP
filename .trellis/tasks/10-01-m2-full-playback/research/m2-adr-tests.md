方法：測試名稱用 grep 在 `app/test/`、`app/integration_test/`、`app/packages/fmp_lints/test/` 確認存在；
PR 用 `git log -S"<測試名>"` 找第一個加入該測試的 commit，再找合併它的 merge commit，
並對照 `gh pr view` 的描述。測試檔路徑省略 `app/` 前綴。沒有實際跑 `flutter test`。
「PR」欄寫第一個加入該測試的 PR；與表上 PR 編號不同時在備註說明（例如 M1 的 #187 已有、M2 沿用）。

## 需要主對話決定

1. **0016「快取庫跨類別淘汰」**：ADR 0016 §如何確認原文是「快取庫跨類別淘汰到上限以下」，但 `lib/data/cache/cache_tables.dart` 的 `CacheCategory` 在 M2 只有 `image`（`cache_store_test.dart` 的 `stored format` 也只驗 `category` 為 `image`）。現有測試測的是「跨插件、同一類別」的 LRU 淘汰。要不要算滿足、或把真正的跨類別測試延到有第二個類別的里程碑，我沒有拍板。
2. **0018「連續下一首播放」**：表上字面可讀成兩種：(a) 連續多次「下一首播放」（play next）的排序，我對到 `queue_model_test.dart` 的 `play next …`、`two in a row play in the order they were chosen`；(b) 連續按「下一首」（next）往下播，對到 `in order` 群組的 `plays in order from the start index`、`next stops at the last track when loop is off`。兩者在 `queue_model_test.dart` 都有測試，但哪個才是驗收指的，請確認。
3. **0016「各頁離線狀態（M2 存在的畫面）」的範圍**：表上 PR 是 2、15、18a，我對了外殼、搜尋、歷史、播放頁四項。`design.md` §5.4 另列兩處，不在表上的 PR 範圍，我沒計入統計：
