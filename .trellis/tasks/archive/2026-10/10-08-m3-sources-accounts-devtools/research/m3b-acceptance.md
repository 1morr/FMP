# M3b 驗收紀錄（2026-10-14～15）

逐項對照本任務 `implement.md`「## M3b 驗收」的 9 個步驟。證據類型：
- **實測**：實機、執行時；
- **PR 實機**：各 PR 合併前、在同一份程式碼上做的實機，證據在該 PR 描述；
- **測試**：單元、widget 或整合測試。

這次沒有登入任何帳號，所有真實連線都是匿名。截圖只留在 session 暫存目錄，沒有放進來：搜尋結果與直播間是第三方內容，部分路徑含使用者名稱。

## 環境

- **Android 模擬器**：AVD `Medium_Phone`，直向，介面語言英文；dev flavor debug。
  - 插件用開發入口（`--fmp-dev-plugin`）裝：`fmp-test`、B 站、YouTube。
  - 這樣裝的插件沒有 `checks.json`，所以健康檢查改在 Windows 做。
- **Windows**：dev flavor **release**（§8 的項目），介面語言繁中。
  - 官方插件從插件庫安裝：B 站 1.5.0、網易雲音樂 1.3.0、YouTube 1.2.0；另有 `fmp-test`。
- **程式碼**：`main` 在 #253 之後（M3b 最後一個功能 PR），加上 `fmp-plugins` #13、#14。

## 操作上的意外（不影響結果）

Windows 上用鍵盤注入時，**左 Windows 鍵卡在按下狀態**（`GetAsyncKeyState` 是 `-32768`）。在這個狀態下打字，`a` 會變成 Win+A、`f` 會變成 Win+F，所以「快速設定」面板與「意見反應中樞」被打開了。

- 我只送了 Windows 鍵的放開事件和兩次 Esc，關掉那個面板；沒有改到任何系統設定，電腦也沒有被鎖定。
- 「意見反應中樞」可能還開著，沒有在裡面做任何操作。
- 之後每次打字前都會先檢查修飾鍵的狀態（`winkey.ps1`）。
- 第 4 步因此改為引用 PR 13 的證據。
