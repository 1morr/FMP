# M2 PR 17：播放列三段與快捷鍵全表

M2 `design.md` §9.2、§9.5、§7.6（音量、靜音、輸出裝置）；ADR 0024 §決定 5、§決定 8。依賴 PR 10、PR 13。播放頁、右欄的歌詞與佇列在 PR 18a。

## 目標

播放列依內容區寬度分三段，放齊 M2 的控制項：
- 音量與靜音、Windows 的輸出裝置選單，可以從 UI 操作（PR 13 只做到控制器）；
- App 內的快捷鍵補齊 design §9.5 的全表，並照同一條輸入框規則運作；
- 只有圖示的按鈕都有附按鍵的 tooltip。

## 要做的

### 播放列三段（design §9.2）

| 內容區寬度 | 控制項 |
|---|---|
| ≥ 840 | 隨機、上一首、播放、下一首、循環、輸出裝置（只在 `PlaybackSupport.outputDeviceSelection` 為真時）、靜音鈕＋音量滑桿 |
| 600–839 | 上一首、播放、下一首、音量圖示（點開滑桿）、「⋯」（隨機、循環、輸出裝置） |
| < 600 | 播放、下一首 |

- **寬度**：「內容區寬度」是外殼裡導覽以外的整塊。播放列的分段依它決定，與將來的右側面板無關。
- **音量**：
  - 滑桿是 0–100%，拖曳時即時套用（控制器的 `setVolume` 已經會取消靜音）；
  - 靜音鈕切換 `toggleMute`，圖示反映靜音與音量大小；
  - 600–839 的音量圖示點開彈出式滑桿，裡面也能切靜音；
  - 「靜音與音量分開記」（PR 13 擁有者決定）：靜音中拖音量就是取消靜音，音量拖到 0 不算靜音。
- **輸出裝置**：
  - 選單列出「系統預設」與 Windows 的音訊裝置，目前的打勾；不列 mpv 的 `openal` 這類內部輸出（PR 13 擁有者決定）。
  - 選了就呼叫 `selectOutputDevice`，並記住偏好（PR 13 已經寫好）。
  - 控制器要對外提供裝置清單、目前裝置與音量／靜音的 stream，或同等的可觀察狀態，給 UI 用。
  - Android 不顯示這個鈕。
- **輸出裝置失敗**（擁有者決定，這個 PR 處理 PR 13 留下的那條）：
  - 播放中記住的裝置開不起來（`OutputDeviceFailed`）時，這次執行改用系統預設輸出，維持暫停，並以統一提示顯示「音訊輸出裝置無法使用，已改用系統預設」（取代 PR 13 的那句提示，三語言）；
  - 記住的偏好不清掉，下次啟動或裝置清單再出現它時照 PR 13 的規則再用；
  - 按播放就能從原位置繼續，不會再撞同一個裝置。
- **狀態文字**：照現有的「重試中」「等待網路連線」「試聽」，PR 12 已有，維持不變。
- **啟動恢復後的進度**：還沒按播放時，進度條與時間顯示恢復的位置，不是 0:00（PR 14 留下的）。曲目時長已知就顯示時長；未知時維持現在的顯示。拖這個進度條等於改恢復的起點（控制器的 `seek` 在沒有來源時已經會改 `_restoredPosition`）。
- **點空白處開播放頁**：延到 PR 18a，與播放頁一起做，這個 PR 不加佔位路由。
- **tooltip 與語意**：
  - 只有圖示的按鈕都有 tooltip（附按鍵，例如「隨機播放（Ctrl+S）」）與語意標籤，三語言（翻譯檔的 `*Tooltip`）；
  - 修掉 tooltip 與 label 同字、MSAA 讀成「X. X」的重複（PR 10、PR 15 留下的：搜尋結果「⋯」、清除全部歷史）。做法是 `IconButton` 的 tooltip 與 icon 的 `semanticLabel` 不重複給。

### 快捷鍵全表（design §9.5）

- 把 `shell_shortcuts.dart` 抽成共用的 `PlaybackShortcuts`，外殼包一層；播放頁那層在 18a 包。
- **新增**：
  - Ctrl+↑／↓：音量 ±5%，夾在 0–100%；靜音中按，就是取消靜音並調整；
  - Ctrl+S：隨機；
  - Ctrl+R：循環；
  - Esc：關閉最上層。這個 PR 的範圍是對話框與彈出的選單或滑桿，播放頁在 18a。
- **延到 18a**：Ctrl+L、Ctrl+Q，要有播放頁才有意義。
- **輸入框規則**，照 design §9.5 的一句話：導覽類（Esc、F6、Ctrl+F、Ctrl+,）在輸入框內也有效，其餘都讓給輸入框。用同一個 `TextInputAwareAction`。
- 對話框開著時，播放類快捷鍵照 M1 不作用。

## 驗收

- `player_bar_test.dart` 的 `controls per width`：
  - 邊界 599／600／839／840 各段的控制項正確；
  - Android 宣告下沒有輸出裝置鈕；
  - 曲名 ≥ 160dp。
- **音量**：
  - 拖滑桿改音量並取消靜音；
  - 靜音鈕切換；
  - 600–839 的彈出滑桿；
  - Ctrl+↑／↓ 的 ±5% 與夾取。
- **輸出裝置**：
  - 選單項目：系統預設＋裝置、沒有 `openal`、目前的打勾；
  - 選了會呼叫控制器；
  - 失敗時這次改用系統預設，偏好不清，提示文字正確，再按播放不再撞同一個裝置。
  - 控制器與 UI 各有測試。
- **恢復後的進度**：顯示恢復的位置；拖它會改起點。
- **快捷鍵**：`app_shell_test.dart` 的 `shortcuts` 群組要有：
  - 新鍵各一例；
  - 在搜尋框內按 Ctrl+S 不切隨機、按 Esc 有效；
  - 對話框開著時不作用。
- **tooltip**：附按鍵、三語言；語意標籤不再重複。
- **golden 三段**：`--update-goldens` 後由主對話人工看圖。
- **guideline** 測試。
- **本機**：`dart format`、`dart analyze --fatal-infos`、`flutter analyze`、`flutter test` 全綠；`install_search_play_test.dart` 與 `toast_layering_test.dart`（Windows）通過。
- **實機**（重播／測試插件）：
  - Windows：
    - 每個快捷鍵各按一次，包括在搜尋框內按 Ctrl+S 不切隨機、Esc 有效；
    - 拖寬視窗經過 600、840 兩個邊界，看控制項換段；
    - 音量、靜音、輸出裝置選單；
    - 恢復後的進度顯示。
  - Android：三段在直向與橫向。
