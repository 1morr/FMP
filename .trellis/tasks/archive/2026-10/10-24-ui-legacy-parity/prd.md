# U UI 對齊舊版

## Goal

擁有者試用 M5 的 dev 版後認為新版 UI「連舊版都完全比不過」，例如匯入 1195 首的歌單時看不到進度。所以在 M6 之前插入這個里程碑：**以舊版 UI 為底，再在上面優化**（擁有者 2026-10-24），之後的功能疊在對齊後的 UI 上。

## Background

- 決策來源：
  - 逐項對照 94 項：`research/compare-browse.md`（B-01–B-34）、`research/compare-library.md`（L-01–L-34）、`research/compare-playback.md`（P-01–P-26）。每項的「我的看法」是建議。
  - 選擇頁（artifact `DSNLK5Rb4HaGVrsmunpsos`，collection `choices`）：4 項明確「照舊版」（B-19、B-33、L-27、P-06）。另外 90 項選了「照建議」，但擁有者說那是因為沒有畫面，不當作決定。
  - 設計稿（artifact `FxhPkgXUX8t4jK3f2uA1Jv`，只有擁有者看得到；原始檔在 `research/design/`）：8 個畫面 × iPhone／Windows／Mac，22 組 A／B 選擇點。
- 擁有者看過設計稿後決定「全都按推薦」（2026-10-24）：
  - 有選擇點的照設計稿的推薦；
  - 其餘照對照文件的建議；
  - P-06 的「打亂」要做真正的打亂。
- 決定記在 ADR 0035。它推翻 ADR 0024 §決定 1、3、4、5、8 與 ADR 0033 §決定 5 的部分內容，並補充 ADR 0018 §決定 5。技術設計見 `design.md`。
- 環境：主力開發在 Mac。macOS／iOS 版目前顯示「此平台尚未支援」，Mac 上的完整測試與 Windows 虛擬機都有限制，見 `research/mac-environment.md`。

## Requirements

每條後面是對照項目編號。「照舊版」＝舊版的行為與外觀；「合併」＝保留新版並補上所列的舊版部分；「保留」＝不動。

### R1 外殼、導覽、主題

- R1.1 導覽六項：首頁｜搜尋｜音樂庫｜**佇列**｜電台｜設定，各寬度同一組；手機的佇列是整頁（B-17、P-03、P-21）。
- R1.2 側欄照舊版：72↔256dp 可展開、顯示 FMP 名稱，展開狀態依裝置記住（B-18）。
- R1.3 頁頂照舊版置中 AppBar（B-20）。
- R1.4 播放列橫跨整個視窗（P-13），頂端 2dp 進度細線，滑鼠移入時變粗並顯示時間，可點可拖（P-12）。保留新版的三段控制與「點擊區和按鈕分開」（P-11、P-13）。
- R1.5 主題與元件主題照舊版（B-33）：預設種子色與 8 個 preset、卡片、輸入框、清單列、導覽指示。
- R1.6 外觀設定照舊版（L-27）：主題模式、主題色（preset 與自訂色）、字型、語言。字型是每個平台一份固定清單，同舊版的做法，清單內容改成繁中為主。
- R1.7 Windows 自繪標題列，舊版樣式（B-19）。
- R1.8 右側面板：沒有曲目時不顯示（P-15）；補「下一首」、加入歌單鈕，點封面或標題開原網頁（P-14）。
- R1.9 不做液態玻璃，全平台同一套舊版風格的 Material（設計稿 APL-1）。
- R1.10 舊資料匯入改成會匯入 `primaryColor`、`fontFamily`、`railExpanded`、搜尋歷史；不補匯已經匯入過的資料（ADR 0035 §決定 12）。

### R2 Apple 平台慣例（設計稿 APL-2–5）

- R2.1 Mac 自繪標題列：與 Windows 同高同色，紅綠燈在左。
- R2.2 Apple 平台的快捷鍵用 ⌘ 取代 Ctrl；開佇列用 ⌥⌘U（Apple Music 的慣例），避開 ⌘Q。
- R2.3 繁中字型：Apple 平台用蘋方，Windows 用微軟正黑體。
- R2.4 iPhone 的安全區域與右滑返回。
- U 只做 Dart 側並以 widget 測試驗證；原生部分（Mac 標題列）與實機驗證交給 macOS／iOS 平台任務。

### R3 播放頁

- R3.1 寬版照舊版：左封面加控制、右歌詞（5:7）；沒有歌詞時單欄，M7 之前一律單欄（P-16）。取消方案 B 的分頁與三欄。
- R3.2 控制區照舊版：80dp 實心播放鍵、曲名置中粗體、無毛玻璃底板（P-02）。
- R3.3 頂列補回加入歌單、輸出裝置與音量（桌面）、資訊鈕（P-01）；資訊鈕開曲目詳細，窄版用底部面板（P-26）。
- R3.4 封面大圓角加陰影（P-17）；上滑開啟、下滑關閉（P-19），保留 Esc 與佇列清空時自動關閉。
- R3.5 窄版：M7 之前隱藏封面／歌詞切換（P-20）；橫向手機用舊版的矮版面（P-24）。
- R3.6 保留：背景（P-18）、倍速選單（P-23）。

### R4 佇列

- R4.1 頂部照舊版（P-06）：
  - 跳到頂／底；
  - 「正在播放第 n 首／共 m 首」橫幅，點了捲到目前這首；
  - Mix 標題、Mix 續取時的轉圈；
  - **打亂**：真正重排，目前這首移到第一位，Mix 時停用，隨機開著時重新產生一輪；
  - 清空（要確認）；
  - 空佇列的引導，含「去搜尋」。
  
  保留新版的隨機語意說明。
- R4.2 每列：一鍵「×」移除、拖曳把手、選單（P-04）。
- R4.3 正在播放那一列的封面疊動態遮罩，標題主色粗體（P-05，佇列與歷史共用）。
- R4.4 保留：自動捲動（P-22）。

### R5 歷史

- R5.1 頂部照舊版（P-07）：統計卡（今日／本週／全部）、音源篩選、日期、搜尋、排序（新到舊、舊到新、播放次數）。
- R5.2 日期分組：舊版的時間軸圓點、首數、可折疊（P-08）。
- R5.3 每列保留新版副標，補時長與音源圖示（P-09）。
- R5.4 保留單筆刪除不確認；補「刪除此曲所有紀錄」與多選批次刪除（P-10）。
- R5.5 載入中轉圈、失敗可重試、空狀態加「去搜尋」（P-25）。

### R6 搜尋與瀏覽

- R6.1 所有曲目清單都標示正在播放的那一首，含分 P（B-01、B-34）。
- R6.2 「全部音源」混合搜尋，預設選它（B-02）。
- R6.3 搜尋歷史（B-03）。
- R6.4 捲到底自動載入下一頁；按鈕留著，自動載入失敗時用來重試（B-04）。
- R6.5 插件介面加選填的播放數，顯示在曲目列與排行；VIP 標記延後（B-05）。
- R6.6 首頁（B-08、B-09、B-15、B-16）：
  - 卡片照舊版的底色，桌面有捲動箭頭；
  - 歌單卡與電台卡有選單；
  - 有「建立歌單」入口；
  - 不放「正在播放」卡。
- R6.7 電台頁（B-10、B-11、B-28）：
  - compact 用清單、expanded 以上用網格；
  - 平常開播的排前面，按排序鈕進入手動排序模式（舊版做法）；
  - 新增對話框補說明。
- R6.8 多選補「下一首播放」與「取消全選」（B-12）。
- R6.9 探索頁下拉重新整理（B-21）。
- R6.10 錯誤狀態用 error 色圖示，另有區塊級的緊湊橫條（B-22）；轉圈下面有說明文字（B-23）。
- R6.11 曲目列的時長用固定欄寬（B-26）。直播間列未開播時封面灰階、播放鈕停用，有分區標籤就顯示（B-27）。
- R6.12 保留：B-06（不做排序）、B-07、B-13、B-14、B-24、B-25、B-29–B-32。

### R7 音樂庫、匯入、設定

- R7.1 帳號匯入歌單改成全頁：總進度、每張歌單「已匯入 n／M 首」、取消（L-01）。
- R7.2 網址匯入：確定式進度、目前曲名、取消；插件沒給總數時顯示「已讀 n 首」（L-02）。
- R7.3 歌單刷新：卡片上轉圈，詳情頁顯示計數（L-03）。
- R7.4 外部匯入補一行目前曲名（L-04）。
- R7.5 音樂庫（L-08、L-10、L-11、L-12）：
  - 所有寬度都用格狀卡片；
  - 卡片有來源圖示；
  - 匯入圖示換回連結圖示；
  - 載入中有轉圈，錯誤可重試。
- R7.6 歌單詳情用 280dp 模糊頂圖，補總時長與來源徽章（L-13）。
- R7.7 編輯歌單時可以「從歌曲封面選」（L-17）。
- R7.8 加入歌單補歌曲資訊卡；手機用底部面板，桌面用對話框（L-18）。
- R7.9 刪除類的確認一律用紅色確認鈕，共用一個元件（L-19）；選單裡的刪除項目上色（L-34）。
- R7.10 網址匯入對話框補來源圖示（L-20）；帳號歌單補全選，主要動作鈕放底部（L-23）。
- R7.11 設定保留 list-detail（L-25），分組列加摘要（L-33），補音質說明文字（L-30）。
- R7.12 保留：L-05–L-07、L-09、L-14–L-16、L-21、L-22、L-24、L-26、L-31、L-32。

## Acceptance Criteria

- [ ] R1–R7 每一條都和設計稿一致：
  - Android 模擬器（手機直向、橫向 914dp）每一條都驗；
  - Windows 驗桌面互動與平台實作：側欄 hover、播放列細線、標題列、首頁箭頭、字型；
  - R2 以 widget 測試驗。
- [ ] 匯入 1000 首以上的歌單時看得到「已匯入 n／M 首」，而且能取消。取消後的歌單狀態照 `design.md` §8（R7.1、R7.2）。
- [ ] 佇列的打亂把目前這首放第一位、Mix 時停用（R4.1）。
- [ ] 舊資料匯入帶入主題色、字型、側欄展開與搜尋歷史（R1.10）。
- [ ] ADR 0035 已採納；ADR 0018、0024、0033 被推翻或補充的段落都有指向 0035 的補充。
- [ ] `implement.md` 的 PR 0–18 都已合併，CI 綠。
- [ ] 擁有者以 dev 版試用後認可。

## Out of Scope

- 歌詞（M7）：歌詞相關的頂列操作與歌詞面板內容；寬版播放頁的右欄在 M7 才出現。
- 桌面整合設定（L-28，M8）、關於頁（L-29，M9）。
- VIP 標記（B-05）、熱門評論與串流資訊（P-14）、搜尋排序（B-06）、搜尋頁的「歌單中的結果」（B-07）。
- macOS、iOS 的平台層、原生標題列與實機驗證：交給各自的平台任務。擁有者 2026-10-24 決定的順序是 U → macOS → iOS → M6，Linux 照舊排在後面。
- 已經匯入過舊資料的使用者補匯四項設定。
