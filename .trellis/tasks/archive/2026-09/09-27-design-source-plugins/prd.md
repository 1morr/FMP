# 設計第 1 項：音源插件化

## 目標

單一註冊點、音源宣告能力；新增音源＝新增一個目錄＋註冊一行；UI 依能力自動出現入口；UI 與 service 沒有針對特定音源的分支。
區分可播放音源、僅元資料（匯入）音源、歌詞源，統一匹配流程。

需求來源：parent `prd.md` 階段二第 1 項；`questions.md` G3、E5、B3、B11、B14、D4、D9（按推薦）；ADR 0009–0013 已定的音源插件義務：
遮蔽名單（0011）、API client 與 `AuthRequirement`、登入方式、憑證無效判定（0012）、錯誤對應表與重試策略（0013）。

## 現況（證據）

- 舊版已有小介面（`SourceCapability` 系列），三個 adapter 各自 `implements` 一組（`docs/audit/sources.md` §1–§2）。
- 問題不在介面形狀，而在繞過：新增一個音源最少改 15 檔、同網易程度約 54 檔；50 處音源分支散在 28 檔；電台、Mix、遠端歌單寫死特定音源（`sources.md` §3–§4）。
- 匹配：歌單匯入與歌詞各有一套評分，自動匹配與手動重搜用不同的音源集合；歌詞「命中即停」不跨源比較（`sources.md` §5）。

## 研究結論（`research/peer-plugin-interfaces.md`、`research/capability-modeling-and-matching.md`）

- 同類專案共通能力：搜尋、串流解析、登入、歌詞；多數加收藏／匯入。MusicFree（AGPL-3.0）、LX Music（Apache-2.0）用 JS 腳本插件；Spotube（BSD-4-Clause）有插件系統；Listen1 為 provider 物件。
- 腳本插件的價值在於「使用者自行安裝來源、免發版修補」；代價是安全、除錯、測試、iOS Guideline 2.5.2（不得下載執行程式碼）風險。
- Dart 能力宣告：能力列舉（給 UI）＋每個能力一個小介面（給型別系統），並用結構測試檢查兩者一致。先例 AetherTune（0BSD；2026-07 建立、2 星，僅作參考）。
- 匹配：Spotube 以快取＋使用者可改選處理元資料→音訊的匹配；同類專案都沒有自動評分的歌詞匹配，FMP 舊版是唯一做評分的。
- 契約測試：Dart 生態沒有現成框架；以共用 test helper＋各音源 fixture 落地。

- 腳本引擎：`flutter_js` 0.8.7（2026-01，五平台：QuickJS／JavaScriptCore）；`hetu_script` 0.6.4（Spotube 採用，Dart 風格小眾語言）。YouTube.js（MIT，2026-09 仍維護）官方只寫支援 Node.js、Deno、瀏覽器，解密需宿主提供 eval 與 fetch。

## 已決定

- D1（使用者 2026-09-27）：採**執行期 JS 腳本插件**，並**納入這次重寫**（為此項明確解除功能凍結）。目的是讓使用者能以 AI Agent 生成並安裝自己的音源；不上架任何商店。
- D2（使用者 2026-09-27）：**內建音源現在就全部做成腳本**（B 站、網易、YouTube、Spotify／QQ 匯入、歌詞源）；YouTube 先做有時限的可行性驗證，失敗則暫以 Dart 實作同一介面。
- D3（使用者 2026-09-27）：**App 不內建任何來源**；官方插件放獨立 repo（`1morr/fmp-plugins`，自有 CI 與 `index.json`），使用者在 App 內從插件庫安裝；可加自訂插件庫、可從檔案／網址安裝；更新只在打開插件頁或手動時檢查；首次啟動引導安裝；舊版升級時提示安裝舊資料用到的音源插件。
- 其餘依研究寫入 design.md：JS（非 hetu）、宿主 API 範圍、manifest、安裝時顯示網域並警告、統一匹配流程。

## 需求

- R1 一套 `SourcePlugin` 介面；App 其他部分只認介面與能力宣告，沒有針對特定音源的分支。
- R2 所有來源是 JS 腳本＋manifest；App 不內建來源，從插件庫（官方或自訂）、檔案或網址安裝，以 SHA-256 驗證。新增音源＝在插件庫新增一個目錄（或使用者自行安裝腳本）。
- R3 腳本只能經宿主 API 動作：網路請求一律經網路層並受網域清單限制；憑證只能讀自己音源的；沒有檔案系統。
- R4 能力宣告驅動 UI；僅元資料來源與歌詞源以能力區分，不另立型別。
- R5 匹配用一份共用評分核心、跨來源比較、使用者可改選且改選後不重算、失敗項目保留並標示。
- R6 腳本插件可用錄下的 HTTP 回應跑契約測試。
